#### The following enhancements have been made to the ANY.RUN Cloud Sandbox connector in version 2.1.1:

- Enhanced the result cards to provide a more consistent and intuitive user experience across the following ANY.RUN Cloud Sandbox Pluggable Enrichment playbooks: 
    - ANY.RUN Analyze File in Windows Sandbox
    - ANY.RUN Analyze File in Linux Sandbox
    - ANY.RUN Analyze File in Android Sandbox
    - ANY.RUN Analyze URL in Windows Sandbox
    - ANY.RUN Analyze URL in Linux Sandbox
    - ANY.RUN Analyze URL in Android Sandbox
- The following improvements are made to the result cards:
    - Standardized verdict color accents to make analysis results easier to identify:
        - Red - Malicious
        - Yellow - Suspicious
        - Gray - Unknown/No data
        - Green - Whitelisted
    - Renamed the action button in the enrichment_summary Description field for pluggable enrichment from `Click` to `Open ANY.RUN` to make its purpose clearer.
    - Removed the background color for the action button for a cleaner and more consistent interface.
